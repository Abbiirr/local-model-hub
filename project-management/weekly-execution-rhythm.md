# Weekly Execution Rhythm

## Daily loop

- Pick one task from `task-breakdown.csv`.
- Confirm its phase gate and non-goals.
- Build the smallest testable slice.
- Add or update tests.
- Record external source if engine behavior changed.

## End-of-week review

- Update gate status.
- Update risk register.
- Re-run relevant acceptance tests.
- Record blocked decisions.
- Cut scope before adding scope.

## Rule

No week ends with undocumented engine assumptions. If an engine did something unexpected, record the observed behavior and source/version.
